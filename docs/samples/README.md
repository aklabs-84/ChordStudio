# 샘플 곡 (장르별 데모)

"이 앱으로 어떤 곡을 만들 수 있는가"를 보여주기 위한 샘플 4곡입니다. 누구나 한 번쯤
들어봤을 법한 **머니코드(I-V-vi-IV, "Let It Be" 진행)** 하나로 벌스·코러스를 전부
통일해, 장르가 달라도 멜로디가 귀에 익도록 만들었습니다.

## 불러오는 방법

각 앱 탭(만들기/레슨)의 **"곡 불러오기"** 버튼으로 아래 파일을 선택하면 바로 재생할
수 있습니다.

## 화성 구성

모든 코드 섹션(인트로/벌스/프리코러스/코러스/아웃트로)이 동일한 4마디 진행을 씁니다.

```
I → V → vi → IV   (예: C 키 기준 C → G → Am → F)
```

## 곡 구성

기본 생성기는 `Intro → 벌스 → 프리코러스 → 코러스 → 아웃트로` 한 바퀴만 도는데,
샘플들은 실제 곡처럼 벌스·코러스를 한 번 더 반복하도록 재생 순서를 늘렸습니다.

```
인트로 → 벌스 → 프리코러스 → 코러스 → 벌스 → 프리코러스(2) → 코러스(파이널) → 아웃트로
```

## 곡별로 보여주는 것

화성(I-V-vi-IV)은 4곡 모두 같지만, 장르별 BPM·스윙·드럼/베이스/피아노 패턴은 그대로
달라서 같은 코드 진행이 얼마나 다르게 들리는지 비교할 수 있습니다.

- **`sample-pop.json` (팝)** — 프리코러스(2)의 마지막 마디(IV)를 둘로 쪼개 7th를
  끼워 넣어 파이널 코러스 진입이 더 팽팽하게 들립니다. 파이널 코러스는 하이햇을
  촘촘하게, 스네어 필인을 더 채워 확실히 "커진" 느낌을 줍니다.
- **`sample-lofi.json` (로파이)** — 인트로·벌스의 피아노/베이스를 프리셋의 "브로큰
  아르페지오" 변형으로 고정해, 화음을 한 번에 안 치고 흩어 치는 로파이 특유의 질감을
  들려줍니다. 파이널 코러스엔 스트링 패드를 살짝 얹어 공간감을 더했습니다.
- **`sample-rock.json` (록)** — 파이널 코러스 마지막 마디에 크래시 심벌 + 탐 필인,
  거기에 맞춘 킥 드럼 변형을 넣어 다음 섹션으로 넘어가는 순간이 확실히 들리게
  만들었습니다.
- **`sample-jazz.json` (재즈)** — 베이스는 프리셋 기본값(코드가 바뀌기 직전 접근음을
  넣는 워킹 베이스)을 그대로 살렸고, 프리코러스(2) 끝에 도미넌트 7th를 한 번 더
  끼워 파이널 코러스로 자연스럽게 이어지게 했습니다. 파이널 코러스 피아노는 아르페지오
  스타일로 바꿔 워킹 베이스 위에서 코드가 더 움직이는 느낌을 줬습니다.

## 참고

- BPM·스윙·조성은 생성기가 고른 값을 그대로 쓰고, 화성만 I-V-vi-IV로 고정한 뒤 위
  항목들을 손으로 다듬었습니다.
- 앱/엔진 코드는 건드리지 않았고, 순수 데이터(JSON) 파일입니다.
