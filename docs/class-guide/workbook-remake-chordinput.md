## STEP 0. 오프닝: 리메이크의 마법 (10분)

원래 잔잔한 피아노 발라드였던 노래가 **신나는 사이버펑크 록**이나 **몽환적인 로파이 힙합**으로 변신한다면 어떨까요?

* **원곡의 정체성:** 코드 진행(화성)과 멜로디의 뼈대
* **리메이크의 핵심:** 리듬과 편곡 스타일(장르)을 180도 바꾸기!

강사님이 들려주는 리메이크 비포/애프터 데모를 듣고, 오늘 내가 리메이크해보고 싶은 노래를 마음속으로 떠올려 보세요.

## STEP 1. 선행 이론: 코드의 종류와 감정의 색채 (20분)

코드는 단순히 알파벳 글자가 아니라, 음들이 모여 만드는 **"감정의 물감"**입니다.

### 1) 3화음 (기본 물감 3가지 음)
* **메이저 (C, G, F 등):** 아무것도 안 붙은 기본 코드. **밝고, 당당하고, 희망찬 느낌**
* **마이너 (Am, Dm, Em 등):** 뒤에 `m`이 붙은 코드. **슬프고, 아련하고, 차분한 느낌**

### 2) 7화음 (고급 물감 — 음 하나 더 얹기)
음 하나를 살짝 더 얹으면 카페나 영화 음악처럼 세련된 소리가 납니다:
* **maj7 (Cmaj7, Fmaj7):** 구름 위를 걷는 듯한 **낭만적이고 따뜻한 느낌** (시티팝, 로파이에 단골!)
* **m7 (Am7, Dm7):** 너무 슬프지 않고 **도시적이고 감성적인 느낌**
* **7 (G7, C7):** 무언가 다음 코드로 넘어가고 싶어 하는 **긴장감 넘치는 느낌**

```
 [ C ]        ➔      [ Cmaj7 ]       ➔       [ C7 ]
(순수하고 밝음)         (따스하고 몽환적)        (긴장감 & 추진력)
```

### ✅ 체크리스트
- [ ] 메이저(밝음)와 마이너(어두움)의 소리 차이를 구별할 수 있다.
- [ ] `maj7`이나 `m7`처럼 7이 붙으면 소리가 더 풍성해진다는 것을 안다.

## STEP 2. 명곡들의 코드 진행 비밀 파헤치기 (15분)

세계적인 히트곡들은 저마다의 황금 공식 코드 진행을 품고 있습니다.

### 대표적인 3대 명곡 진행
1. **머니코드 (I - V - vi - IV):**
   * 진행 예시: `C → G → Am → F`
   * 수록곡: 비틀즈 *Let It Be*, 마룬5 *She Will Be Loved*, 에드 시런 노래 다수
   * 특징: 언제 들어도 편안하고 자연스럽게 감정이 고조됨
2. **투-파이브-원 (ii - V - I):**
   * 진행 예시: `Dm7 → G7 → Cmaj7`
   * 수록곡: 마룬5 *Sunday Morning*, 수많은 재즈 & R&B 명곡
   * 특징: 물 흐르듯 세련되게 제자리로 돌아오는 마법 같은 진행
3. **감성 발라드 진행 (아이유 밤편지 스타일):**
   * 진행 예시: `Eb → Bb/D → Cm7 → Bb`
   * 특징: 베이스 음이 계단처럼 한 음씩 아래로 내려가며 극강의 아련함을 선물함

## STEP 3. Chordify & Klang에서 노래 코드 파악하기 (15분)

이제 인터넷 악보 사이트에서 내가 원하는 노래의 코드를 직접 찾아봅니다!

### 따라 하기
1. [Chordify](https://chordify.net/) 또는 [Klang Songs](https://songs.klang.io/en)에 접속합니다.
2. 검색창에 좋아하는 노래 제목(예: *Let It Be*, *밤편지*, *Hype Boy* 등)을 검색하세요.
3. 악보 화면에서 다음 3가지를 메모장에 적어둡니다:
   * **Key (조성):** 곡의 기준 음 (예: C, G, Eb, Am 등)
   * **BPM (빠르기):** 숫자로 된 빠르기 (예: 72, 95, 120 등)
   * **마디별 코드 진행:** 네모 칸에 적힌 코드 순서 (예: Intro는 `C | G | Am | F`, Chorus는 `Am | F | C | G`)

> 💡 **꿀팁:** 대부분의 가요는 1마디에 코드가 1개(4박) 들어가거나, 2개(2박씩 반반) 들어갑니다!

## STEP 4. Chord Studio [코드 입력] 탭 마스터하기 (25분)

이제 Chord Studio의 새로운 메뉴인 **`[ 코드 입력 ]`** 탭을 사용하여 악보를 실제 연주 가능한 구조로 빌드합니다!

```
┌────────────────────────────────────────────────────────────────────────┐
│  Chord Studio   [ 만들기 ] [ 레슨 ] [ 가이드 ] [ 코드 입력 (클릭!) ]     │
└────────────────────────────────────────────────────────────────────────┘
```

### 따라 하기 1: 곡 기본 설정 & 악보 사이트 퀵 검색
1. 상단 메뉴에서 **`[ 코드 입력 ]`** 탭을 클릭합니다.
2. 오른쪽 **[곡 기본 설정]** 카드에서:
   * **곡 제목**을 입력합니다 (예: *Let It Be - 록 버전 리메이크*).
   * 사이트에서 확인한 **Key(조성)**와 **BPM(템포)**을 맞춰줍니다.
   * **반주 스타일(장르)**을 골라보세요 (원곡과 전혀 다른 장르를 고르면 더 신선해요!).

### 따라 하기 2: 비주얼 마디 빌더로 코드 입력하기
1. **`🎛️ 비주얼 마디 빌더`** 버튼을 누릅니다.
2. 상단 버튼으로 필요한 섹션을 추가하세요:  
   * `+ 인트로 (4마디)`, `+ 벌스 (8마디)`, `+ 코러스 (8마디)`
3. 각 섹션 카드 안의 흰색 코드 칸에 사이트에서 찾은 코드를 직접 타이핑합니다 (예: `C`, `G`, `Am`, `F`).
   * 올바른 코드를 적으면 칸이 깔끔하게 유지되고, 오타가 나면 붉은색 테두리로 경고해 줍니다.
4. 한 마디에 코드가 2개 들어가는 구간은 **`[4박]`** 버튼을 눌러 **`[2박]`**으로 바꿔줍니다!
5. 상단의 **다이아토닉 코드 팔레트**를 누르면 해당 조의 어울리는 화음이 마지막 섹션에 쏙 들어갑니다.

### 따라 하기 3: 섹션 드래그 앤 드롭으로 순서 맞추기 (핵심!)
* 인트로를 나중에 추가해서 맨 아래에 가 있나요? 걱정 마세요!
* 섹션 카드 왼쪽 번호 앞의 **드래그 핸들(`⋮⋮`)**을 마우스로 잡고 맨 위로 끌어올리면 위치가 바로 바뀝니다!
* 또는 카드 오른쪽의 **`[▲ 위로]` / `[▼ 아래로]`** 퀵 버튼을 눌러 원하는 순서(인트로 ➔ 벌스 ➔ 코러스)로 맞추세요.

### 따라 하기 4: 스튜디오 적용
* 하단의 **`[ ✨ Chord Studio에 적용하고 연주 듣기 ]`** 버튼을 누르면 끝!
* '만들기' 탭으로 자동 이동하며, 입력한 코드 위로 드럼과 베이스가 신나게 반주를 시작합니다!

### ✅ 체크리스트
- [ ] 곡 제목, Key, BPM을 정확히 설정했다.
- [ ] 섹션별로 코드를 입력하고 박자(4박/2박)를 조절했다.
- [ ] 드래그 핸들(`⋮⋮`)이나 화살표 버튼으로 섹션 순서를 바르게 정렬했다.

## STEP 5. MIDI 추출 & 개러지밴드 사운드 믹싱 (10분)

1. Chord Studio에서 **"MIDI 파일 저장 (.mid)"**을 누릅니다.
2. **개러지밴드**를 열고 새 프로젝트에 `.mid` 파일을 드래그하여 넣습니다.
3. 리메이크할 장르에 맞춰 악기를 과감하게 바꿔보세요:
   * **신나는 록으로 바꿀 때:** 드럼 ➔ *Heavy Rock Kit*, 피아노 ➔ *Distorted Electric Guitar*
   * **감성 힙합으로 바꿀 때:** 드럼 ➔ *Trap Door Kit*, 피아노 ➔ *Classic Suitcase Piano*
4. 볼륨 밸런스를 맞추고, **[공유] ➔ [노래를 디스크로 내보내기]**에서 **MP3**로 저장합니다.

## STEP 6. Suno AI로 장르 반전 리메이크 완성! (10분)

원곡의 코드 진행을 유지한 채, 인공지능에게 완전히 새로운 장르로 보컬과 풀 트랙을 부르도록 명령합니다!

### 따라 하기
1. [Suno.com](https://suno.com/) 접속 ➔ **Create** ➔ **Custom Mode** 활성화
2. **`Upload Audio`**를 눌러 개러지밴드에서 뽑은 **mp3 파일**을 업로드합니다.
3. 업로드된 파일에서 **`Extend`**를 클릭합니다.
4. **Style of Music (음악 스타일)**에 원곡과 **완전히 반대되는 장르 키워드**를 적어주세요:
   * 예시 (발라드를 팝 펑크로):  
     `Pop punk, energetic driving electric guitars, fast tempo, expressive rock female vocal, anthemic chorus`
   * 예시 (댄스곡을 시티팝으로):  
     `80s Japanese City Pop, nostalgic, slap bass, mellow brass, sparkling synth, sweet female vocal`
5. **Lyrics**에 원곡 가사를 일부 인용하거나 나만의 리메이크 가사를 작성하고 `[Verse]`, `[Chorus]` 태그를 달아줍니다.
6. **Create**를 누르면, 귀에 익숙한 명곡의 코드가 상상치도 못한 최신 트랙으로 재탄생합니다!

## 💡 프로듀서 팁: 리메이크 성공 공식
1. **코드는 지키고, 리듬은 뒤집어라:** 원곡의 뼈대(코드)가 남아있어야 청자가 "아! 그 노래구나!" 하고 은은한 향수를 느낍니다.
2. **Key를 조절하라:** 원곡이 너무 높거나 낮으면 Chord Studio의 [코드 입력] 탭에서 Key를 바꿔 내 목소리나 원하는 악기 톤에 맞출 수 있습니다.
3. **BPM으로 감정을 지배하라:** 같은 코드 진행도 70 BPM에서는 눈물이 나고, 130 BPM에서는 춤을 추게 됩니다!
