## STEP 1. 음악의 재료 알아보기 (15분)

음악은 크게 세 가지 재료로 이루어져 있어요.

| 재료 | 쉬운 설명 |
|---|---|
| **리듬** | 소리가 "언제" 나는지 — 심장 박동처럼 반복되는 규칙 |
| **멜로디** | 음이 하나씩 이어지며 만드는 "노래하는 선" |
| **화성** | 여러 음을 동시에 쌓아서 나는 "분위기" (코드) |

### 따라 하기
1. Chord Studio에서 **"가이드"** 탭을 클릭하세요.
2. 첫 번째 레슨(음악의 3요소)을 엽니다.
3. 리듬 → 멜로디 → 화성 순서로 **"▶ 듣기"** 버튼을 하나씩 눌러보세요.
4. 각각 들었을 때 느낌이 어떻게 다른지 옆 친구와 한마디씩 말해보세요.

> 💡 **예시로 이렇게 생각해보세요:** 리듬만 있으면 "박수만 치는 느낌", 멜로디가 더해지면
> "누군가 흥얼거리는 느낌", 화성까지 더해지면 "반주가 깔린 느낌"이 됩니다.

### ✅ 체크리스트
- [ ] 리듬/멜로디/화성을 각각 들어봤다
- [ ] 셋의 차이를 내 말로 한 문장씩 설명할 수 있다

---

## STEP 2. 머니코드가 뭔지 들어보기 (10분)

**머니코드**란, 많은 히트곡에서 반복적으로 쓰이는 "잘 어울리는 코드 순서"를 말해요.
예를 들어 `C → G → Am → F` 같은 진행이 정말 많은 노래에 나와요. 왜냐하면 이 순서가
안정적으로 들리면서도 감정이 자연스럽게 움직이기 때문이에요.

### 코드 이름 읽는 법 (쉬운 버전)
코드 이름은 이렇게 세 부분으로 나뉘어요.

```
     C      m       7
     ↑      ↑       ↑
   근음   성질    덧붙는 음
  (어떤 음)  (밝은지/어두운지)  (풍부함 추가)
```

- **근음**: C, D, E, F, G, A, B — 코드의 이름표 (어떤 음을 기준으로 쌓았는지)
- **성질**: 아무것도 안 붙으면 "장조(밝음)", `m`이 붙으면 "단조(어두움/차분함)"
- **덧붙는 음**: `7`, `maj7` 등이 붙으면 더 재즈스럽고 풍부한 느낌이 더해짐

### 따라 하기
1. "가이드" 탭 → 두 번째 레슨(코드 이름과 패턴 종류)을 엽니다.
2. **"② 성질"** 항목의 **"▶ 듣기"** — C(장) → Cm(단) → Cdim(감소) → Caug(증가) 순서로
   재생돼요. 밝던 화음이 점점 어둡고 불안정해지는 느낌을 들어보세요.
3. **"③ 덧붙는 음"** 항목의 **"▶ 듣기"** — C(3화음) → C7 → Cmaj7 → Cmaj9 순서로, 점점
   더 풍성해지는 소리를 들어보세요.
4. 아래 **패턴 종류(피아노)** 표에서 코드 / 아르페지오 ↑ / 아르페지오 ↑↓ / 브로큰 4가지를
   하나씩 **"▶ 듣기"** — 같은 진행(C → Am)을 어떻게 다르게 연주하는지가 포인트예요.

> 💡 **패턴 쉬운 설명**
> - **코드**: 모든 음을 한 번에 "쾅" 누르는 느낌
> - **아르페지오 ↑**: 낮은 음부터 하나씩 순서대로 "도미솔"처럼 올라가며 연주
> - **아르페지오 ↑↓**: 올라갔다가 다시 내려오며 연주
> - **브로큰**: 음을 순서대로가 아니라 통통 튀듯 건너뛰며 연주

### ✅ 체크리스트
- [ ] 코드 이름에서 근음·성질·덧붙는 음을 구분할 수 있다
- [ ] 피아노 패턴 4종류의 느낌 차이를 들어봤다

## STEP 3. 장르별로 리듬이 어떻게 다른지 비교하기 (15분)

Chord Studio는 **팝 / 록 / 로파이 / 재즈** 4가지 장르를 지원해요. 장르마다 빠르기(BPM)와
리듬이 딱딱 맞는 정도(스윙)가 달라요.

### 따라 하기
1. "가이드" 탭 → 세 번째 레슨(장르)에서 팝 → 록 → 로파이 → 재즈 순서로 **"▶ 듣기"**.
2. 어떤 장르가 가장 빠르게 느껴지나요? 어떤 장르가 리듬이 살짝 밀리듯 들리나요?
3. 네 번째 레슨(리듬 패턴)에서 킥(북소리)·스네어(짝 소리)·하이햇(잘게 쪼개는 소리)이
   장르마다 어떻게 다르게 배치되는지 들어보세요.

> 💡 **쉬운 비교**
> - **팝/록**: 리듬이 딱딱 맞아떨어져서 신남
> - **로파이/재즈**: 리듬이 살짝 밀리듯 들려서(스윙) 여유롭고 편안함

### 📝 지금 적어보세요
오늘 내가 만들 곡의 장르는 무엇인가요? 그 이유는?

```
장르: ________________
이유: ________________________________________
```

### ✅ 체크리스트
- [ ] 4개 장르를 모두 들어봤다
- [ ] 오늘 만들 장르를 하나 정했다

## STEP 4. AI에게 곡 추천받기 (15분)

이제 Chord Studio의 **"레슨"** 탭(위자드)으로 이동합니다. 여기서부터 진짜로 내 곡을 만들기
시작해요.

### 따라 하기
1. **"레슨"** 탭 클릭 → **"1. AI 추천받기"** 화면으로 이동.
2. 무드 4가지(K-POP 댄스 / 로파이 / J-POP 애니 / 발라드) 중 마음에 드는 것 하나를 클릭.
3. 화면에 자동으로 만들어진 질문 문장을 확인하세요. "K-POP 댄스"를 골랐다면 이렇게 나와요:

   > *"나는 "신나고 통통 튀는 K-POP 댄스곡" 느낌의 곡을 만들려고 해. 이 분위기에 어울리는
   > 조성(키), 템포(BPM), 코드 진행(예: I-V-vi-IV 같은 형태), 곡 구조(벌스/코러스 등)를
   > 추천해줘. 그리고 내가 쓰는 작곡 툴은 팝/로파이/록/재즈 4가지 장르 프리셋만 지원하니,
   > 이 중 어떤 장르가 가장 가까운지도 같이 알려줘. 음악을 전공하지 않은 사람도 이해할 수
   > 있게 쉽게 설명해줘."*

4. **"📋 맞춤 질문 복사하기"** 버튼을 눌러 문장을 복사합니다.
5. ChatGPT 또는 Gemini 탭을 열고 붙여넣기 → 전송합니다.
6. AI가 추천해준 내용 중 아래 항목을 메모하세요.

```
AI가 추천한 조성(키): ________
AI가 추천한 BPM(빠르기): ________
AI가 추천한 코드 진행: ________________________
```

7. Chord Studio로 돌아와 **"다음 단계 ▶"** → **"2. 곡 기획"** 화면에서 실제로 사용할
   장르·조성·BPM을 골라 설정하세요 (AI 추천을 참고하되, 꼭 똑같이 안 해도 괜찮아요).

> 💡 **알아두기:** AI가 팝/록/로파이/재즈가 아닌 다른 장르(예: EDM, 힙합)를 추천했다면,
> 그중 가장 비슷한 느낌의 장르를 골라 사용하면 됩니다.

### ✅ 체크리스트
- [ ] AI에게 질문을 보내고 답을 받았다
- [ ] 조성·BPM·코드 진행을 메모했다
- [ ] "곡 기획" 화면에서 장르·조성·BPM을 실제로 설정했다

## STEP 5. 코러스부터 직접 만들기 (15분)

**왜 코러스부터 만드나요?** 코러스(후렴)는 곡에서 가장 강하고 기억에 남는 부분이라,
여기서 곡의 "얼굴"을 먼저 정하면 나머지 부분은 훨씬 수월하게 만들 수 있어요.

### 따라 하기
1. 단계 칩에서 **"코러스"** 를 클릭해 편집 화면으로 이동.
2. 화면에 있는 **"🤖 AI에게 이 섹션 질문하기"** 박스를 확인하세요. 이미 여러분의
   장르·조성·BPM·섹션 역할이 반영된 질문이 만들어져 있어요.
3. **"📋 맞춤 질문 복사하기"** → AI에게 붙여넣어 코드 진행 아이디어를 받습니다.
4. 화면 아래 **코드 카드**를 클릭해서, AI가 추천한 코드(또는 마음에 드는 코드)로 바꿔보세요.
5. **피아노 패턴**을 코드 / 아르페지오 ↑ / 아르페지오 ↑↓ / 브로큰 중 하나로 선택하고
   **"▶ 재생"** 으로 확인 (재생 버튼을 누르면 지금 편집 중인 이 섹션만 반복 재생돼요).
6. **드럼 격자**에서 칸을 몇 개 눌러 리듬을 추가해보세요. 한 칸씩 누를 때마다
   꺼짐 → 보통 → 세게 순서로 바뀝니다.
7. 잘 모르겠으면 **"🎹 코드·패턴 편집 방법"** 을 펼쳐서 다시 읽어보세요.

> 💡 **AI 추천을 그대로 다 쓸 필요는 없어요.** 마음에 드는 것만 골라서 반영해도 됩니다.
> AI는 참고자료이지 정답이 아니에요.

### ✅ 체크리스트
- [ ] AI에게 코러스용 질문을 보내고 답을 받았다
- [ ] 코드를 최소 1개 이상 바꿔봤다
- [ ] 피아노 패턴을 하나 선택했다
- [ ] 드럼 칸을 몇 개 눌러봤다

## STEP 6. 벌스 만들기 (10분)

**벌스(verse)** 는 이야기를 풀어가는 부분이에요. 코러스보다 차분하게 만들어야
나중에 코러스가 더 돋보여요.

### 따라 하기
1. 단계 칩에서 **"벌스"** 클릭.
2. STEP 5와 같은 순서로: AI 질문 복사 → 코드 바꾸기 → 패턴 선택 → 드럼 칸 조정.
3. **일부러 코러스보다 조용하고 단순하게** 만들어보세요 — 예를 들어 드럼 칸을
   코러스보다 적게 켜거나, 피아노 패턴을 더 차분한 것으로 선택.

> 💡 **비교 팁:** 벌스를 만든 뒤 코러스와 번갈아 재생해서 "차이가 느껴지나?"를 스스로
> 확인해보세요. 차이가 잘 안 느껴진다면 벌스를 더 단순하게 만들어보세요.

### ✅ 체크리스트
- [ ] 벌스 코드/패턴을 코러스와 다르게 만들었다
- [ ] 벌스와 코러스를 번갈아 들어보고 차이를 확인했다

## STEP 7. 인트로 · 프리코러스 · 아웃트로 다듬기 (15분)

| 섹션 | 역할 |
|---|---|
| **인트로** | 곡을 여는 부분. 짧고 단순하게 시작해서 자연스럽게 끌어들여요. |
| **프리코러스** | 벌스에서 코러스로 넘어가는 다리. 긴장감을 조금씩 쌓아 올려요. |
| **아웃트로** | 곡을 마무리하는 부분. 다시 잦아들며 자연스럽게 끝을 맺어요. |

### 따라 하기
1. 세 섹션을 순서대로 클릭하며 STEP 5와 같은 방식(AI 질문 → 코드/패턴/드럼 조정)으로
   다듬어보세요.
2. 시간이 부족하면 기본값을 그대로 두고 넘어가도 괜찮아요 — 코러스와 벌스만 잘
   만들어도 곡은 충분히 완성됩니다.
3. 곡을 더 길게 만들고 싶다면 단계 칩 맨 오른쪽의 **"+ 새 섹션"** 으로 브릿지 같은
   구간을 추가해볼 수 있어요.

### ✅ 체크리스트
- [ ] 인트로/프리코러스/아웃트로를 확인하거나 다듬었다
- [ ] (선택) 새 섹션을 추가해봤다

---

## STEP 8. 곡 완성하고 MIDI로 저장하기 (10분)

### 따라 하기
1. 단계 칩 맨 끝 **"★ 완성"** 클릭.
2. 위쪽 재생 순서(인트로 → 벌스 → 프리코러스 → 코러스 → 아웃트로)를 확인하고
   **"▶ 재생"** 으로 처음부터 끝까지 들어보세요.
3. **믹서**에서 피아노/베이스/드럼/스트링 볼륨을 조절해보고, M(뮤트)이나 S(솔로)를 눌러
   특정 악기만 들어보세요.
4. 마음에 들면 **"MIDI 내보내기"** 버튼을 클릭 — `.mid` 파일이 다운로드됩니다.

> 💡 나중에 이어서 수정하고 싶다면 **"곡 저장 (.json)"** 도 함께 눌러 저장해두세요.

### ✅ 체크리스트
- [ ] 전체 곡을 처음부터 끝까지 들어봤다
- [ ] 믹서로 악기 볼륨을 조절해봤다
- [ ] MIDI 파일을 다운로드했다

---

## STEP 9. 개러지밴드에서 악기 바꾸기 (15분)

### 따라 하기
1. 다운로드한 `.mid` 파일을 더블클릭하거나 개러지밴드로 드래그해서 엽니다.
2. **피아노 / 베이스 / 드럼 / 스트링** 4개 트랙이 자동으로 나뉘어 들어온 것을 확인하세요.
3. 트랙을 하나씩 클릭해서 악기를 바꿔보세요. 예: 피아노 → 일렉트릭 피아노나 신스,
   스트링 → 다른 종류의 패드 사운드.
4. 바꿀 때마다 재생해서 어떤 느낌으로 바뀌는지 비교해보세요.

> ⚠️ **알아두기:** 개러지밴드가 베이스 트랙을 가끔 원래보다 한 옥타브 높은 악기로
> 자동으로 바꿔버릴 때가 있어요. 베이스 소리가 이상하게 높게 들리면, 트랙 악기를
> 일반 베이스 계열로 바꿔주세요. 이건 개러지밴드의 특성이지 여러분이 잘못 만든 게 아니에요.
> 템포(BPM)는 Chord Studio에서 설정한 값 그대로 들어오니 따로 맞출 필요는 없어요.

### ✅ 체크리스트

- [ ] 트랙 악기를 최소 1개 이상 바꿔봤다

## STEP 10. 완성한 곡 들어보기 (5분)

- 개러지밴드에서 완성된 곡을 처음부터 끝까지 재생해보세요.
- 옆 친구와 서로의 곡을 들려주고, 어떤 장르·무드를 골랐는지 이야기해보세요.

### 🎉 오늘 배운 것 정리
```
1. 음악은 리듬 · 멜로디 · 화성으로 이루어져 있다
2. 코드 이름은 근음 · 성질 · 덧붙는 음으로 읽는다
3. 장르마다 BPM과 스윙(리듬감)이 다르다
4. AI에게 막연히 묻기보다, 음악 용어(장르·BPM·코드)를 넣어 물어보면 더 좋은 답을 받는다
5. Chord Studio에서 다듬은 곡을 MIDI로 내보내면 개러지밴드에서 악기를 자유롭게 바꿀 수 있다
```

## 📖 오늘 쓴 용어 사전

| 용어 | 뜻 |
|---|---|
| BPM | 1분에 박자가 몇 번 뛰는지 (숫자가 클수록 빠른 곡) |
| 스윙 | 리듬이 정박에서 살짝 밀리는 정도 (재즈·로파이에 많음) |
| 코드 | 여러 음을 동시에 쌓아서 나는 화음 |
| 머니코드 | 여러 히트곡에 반복적으로 쓰이는 "잘 어울리는" 코드 순서 |
| 아르페지오 | 코드의 음을 동시에 안 누르고 순서대로 하나씩 연주하는 방식 |
| 인트로/벌스/프리코러스/코러스/아웃트로 | 곡을 구성하는 5개 구간 이름 (시작 / 이야기 / 다리 / 후렴 / 마무리) |
| MIDI | 음의 높낮이·길이·세기 정보만 담은 파일 형식. 소리 자체가 아니라 "악보"에 가까워서, 어떤 악기로도 다시 연주할 수 있음 |
