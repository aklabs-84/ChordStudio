# AI와 함께 만드는 나만의 음악 — Chord Studio 2시간 클래스 가이드

> 이 문서는 그대로 복사해서 강의안으로 쓸 수 있도록 만들어졌습니다.
> 핵심 컨셉: **AI는 아이디어를 빠르게 넓혀주는 도구일 뿐, 결국 "내가 원하는 소리"에 가까워지려면
> 리듬·코드·장르 패턴 같은 최소한의 음악 지식이 필요하다.** 이 수업은 그 지식을 Chord Studio 안에서
> 직접 듣고 눌러보며 익히고, 그 지식을 바탕으로 AI에게 더 좋은 질문을 던져 곡을 완성하는 과정입니다.

2. "머니코드" — 대중음악에서 반복적으로 쓰이는 코드 진행이 왜 그렇게 자주 쓰이는지
3. 장르(팝/록/로파이/재즈)마다 BPM·스윙·드럼 패턴이 어떻게 달라지는지 — 귀로 직접 비교
4. AI에게 "막연하게" 물어보는 것과 "음악 용어를 써서" 물어보는 것의 결과 차이
5. Chord Studio → MIDI 내보내기 → 개러지밴드 악기 교체까지, 아이디어가 실제 음악이 되는 전체 파이프라인

## 2. 오리엔테이션 (5분)

- 오늘 만들 결과물을 강사가 먼저 재생해서 들려준다(완성곡 샘플 1개, MIDI를 개러지밴드에서 악기 바꾼 버전).
- 진행 순서를 화면에 띄우고 "우리는 이 순서대로 딱 한 곡을 끝까지 만든다"고 명확히 말한다.
- 오늘 쓸 세 가지 도구를 한 번씩 화면에 띄운다: Chord Studio / ChatGPT 또는 Gemini / 개러지밴드.

**강사 멘트 예시**
> "오늘은 코드 하나, 음표 하나 몰라도 괜찮아요. 대신 이 세 가지 도구를 오가면서 여러분만의 곡을
> 하나 완성해서 가져갈 거예요. AI한테 '멋진 곡 만들어줘'라고만 하면 생각보다 마음에 드는 결과가
> 잘 안 나와요. 오늘 배우는 건 AI에게 '이렇게' 물어보면 훨씬 원하는 결과에 가까워진다는 요령이에요."

## 3. 오늘의 컨셉: AI × 음악 지식 (10분)

**목표:** "AI가 다 해준다"가 아니라 "AI에게 좋은 질문을 하려면 최소한의 음악 언어가 필요하다"를 체감시킨다.

1. 질문 던지기: "AI한테 '신나는 노래 만들어줘'라고 하면 어떤 곡이 나올까요?" (자유 답변 받기)
2. 같은 요청을 두 버전으로 비교 설명:
   - **막연한 질문**: "신나는 노래 만들어줘"
   - **음악 지식이 담긴 질문**: "BPM 128, 장조, I-V-vi-IV 코드 진행에 하이햇이 잘게 쪼개지는 팝 댄스곡 만들어줘"
   - 후자가 훨씬 구체적인 결과로 이어진다는 것을 강조 — "오늘 배우는 이론이 전부 이 두 번째 질문을 만들기 위한 재료"라고 연결한다.
3. Chord Studio의 역할 정의: *"이 앱은 AI가 아니에요. 여러분이 음악 용어(코드/BPM/장르/패턴)를 귀로 확인하면서
   AI에게 보낼 질문을 다듬고, 실제로 들리는 소리(MIDI)까지 만들어주는 '도구'예요."*

## 4. 음악 기본 이론 + 머니코드 (15분)

Chord Studio **"가이드" 탭**을 화면 공유로 열어 진행합니다. (레슨 1, 2 활용)

1. **가이드 탭 → 레슨 1 (음악의 3요소)**: 리듬 / 멜로디 / 화성을 각각 "▶ 듣기" 버튼으로 직접 들려준다.
   - 리듬만 있을 때, 화성이 붙었을 때의 느낌 차이를 학생들에게 먼저 말로 표현해보게 한다.
2. **가이드 탭 → 레슨 2 (코드 이름과 패턴 종류)**:
   - 코드 이름 읽는 법(근음 · 성질 · 덧붙는 음)을 "▶ 듣기"로 확인 — 예: C, Cm, Cmaj7 소리 차이.
   - **머니코드 설명**: 대중음악에 자주 나오는 진행(예: C–G–Am–F, 이른바 "1-5-6-4" 진행)을 귀로 들려주고,
     "이 진행이 왜 여러 히트곡에 반복되는지"(안정적으로 들리면서도 감정 곡선을 만들기 쉬움)를 설명한다.
   - 피아노 패턴 4종류(코드 / 아르페지오 ↑ / 아르페지오 ↑↓ / 브로큰)를 각각 들려주고, 같은 코드라도
     패턴에 따라 분위기가 얼마나 달라지는지 비교시킨다.

**확인 질문(학생에게 던지기)**
- "코드 이름에서 뒤에 붙는 m, 7, maj7은 각각 뭘 바꾸는 걸까요?"
- "아르페지오 패턴은 코드 패턴과 뭐가 다르게 들렸나요?"

## 5. 장르별 패턴 듣기 비교 (15분)

Chord Studio **"가이드" 탭 → 레슨 3(장르), 레슨 4(리듬 패턴)** 활용.

1. 팝 / 록 / 로파이 / 재즈 4개 장르의 "▶ 듣기"를 순서대로 재생 — 학생들에게 BPM(빠르기)과 스윙(리듬이
   딱딱 맞는지, 살짝 밀리는지)의 차이를 느끼게 한다.
2. 레슨 4에서 킥/스네어/하이햇 각 레인이 장르마다 어떻게 다르게 배치되는지(팝·록은 정직한 백비트,
   로파이·재즈는 고스트 노트와 스윙감) 들려준다.
3. **연결 포인트**: "이제 여러분이 만들 곡의 장르를 하나 정할 건데, 그 장르를 고르면 이 리듬감이
   자동으로 반영된다"는 걸 미리 알려준다.

**활동:** 학생 각자 노트(또는 채팅)에 "나는 [장르]로 만들 거야, 이유는 ___" 한 줄을 적게 한다.

## 6. AI에게 곡 기획 물어보기 — 실습 1 (15분)

Chord Studio **"레슨" 탭 (위자드) → 1단계 "AI 추천받기"** 로 진행합니다.

1. 학생들이 각자 맥북에서 Chord Studio를 열고 "레슨" 탭으로 이동.
2. 1단계에서 무드(K-POP 댄스 / 로파이 / J-POP 애니 / 발라드) 중 하나를 고르면, 그 분위기를 반영한
   AI 질문 문구가 자동으로 만들어진다는 것을 보여준다.
3. **"📋 맞춤 질문 복사하기"**로 복사 → 각자 ChatGPT 또는 Gemini에 붙여넣고 답변을 받아본다.
4. AI가 추천해준 조성·BPM·코드 진행·장르를 메모해두게 한다.
5. **2단계 "곡 기획"** 으로 이동 — AI 추천을 참고해서 장르(팝/록/로파이/재즈) · 조성 · BPM을 실제로 선택.

**강사 체크포인트**
- AI 답변이 Chord Studio가 지원하지 않는 장르(예: EDM, 힙합)를 추천했다면, "가장 가까운 팝/록/로파이/재즈
  중 뭐가 비슷할지" 학생과 함께 판단해준다.
- 조성 드롭다운은 장/단조 24개 전체를 지원한다.

## 7. 섹션별로 곡 만들기 — 실습 2 (핵심, 30분)

**여기가 이 수업의 핵심 실습입니다.** 위자드는 곡을 **인트로 → 벌스 → 프리코러스 → 코러스 → 아웃트로**
5개 섹션으로 자동 구성해줍니다. 각 섹션 편집 화면에는 아래 두 가지 도우미가 있습니다.

1. **섹션 역할 설명 박스**(인디고 박스): 이 섹션이 곡에서 어떤 역할을 하는지 한 줄 설명.
2. **🤖 "AI에게 이 섹션 질문하기"**: 지금 장르·조성·BPM·섹션 역할을 반영한 맞춤 질문이 자동 생성됨 →
   복사해서 AI에게 "이 섹션에 어울리는 코드/리듬을 추천해줘"라고 물어볼 수 있음.
3. **🎹 "코드·패턴 편집 방법"** (접어서 펼치는 도움말): 코드 카드, 피아노 패턴 4종류, 드럼 격자 사용법 요약.

**진행 순서 (섹션마다 반복)**
1. 코러스부터 먼저 만든다 — 곡에서 가장 중요한 부분이라 여기서 곡의 "얼굴"을 정하면 나머지가 쉬워짐을 강조.
   - "🤖 AI에게 이 섹션 질문하기" 복사 → AI에게 코드 진행 추천받기 → 코드 카드 클릭해서 반영
   - 피아노 패턴을 코드/아르페지오/브로큰 중 하나로 바꿔보고 "▶ 재생"으로 확인 (재생은 그 섹션만 반복됩니다)
   - 드럼 격자에서 킥/스네어/하이햇 칸을 몇 개 눌러 리듬을 얹어본다
2. 벌스 → 프리코러스 → 인트로 → 아웃트로 순서로 같은 방식 반복(시간이 부족하면 벌스·코러스만 정성껏
   만들고 나머지는 기본값을 유지해도 괜찮다고 안내).
3. 코러스와 확실히 다른 느낌이 나도록(더 차분하게, 또는 긴장감 있게) 유도한다.
4. 마음에 드는 구조를 더 만들고 싶으면 상단 **"+ 새 섹션"**으로 브릿지 등을 추가할 수 있음을 알려준다.

**강사 팁**
- 학생들이 "AI가 추천한 코드를 그대로 다 넣기 vs 마음에 드는 것만 골라 넣기" 둘 다 괜찮다고 알려준다 —
  AI 추천은 참고이지 정답이 아니라는 점을 다시 강조.
- 시간 관리: 30분 중 코러스 10분, 벌스 10분, 나머지(프리코러스/인트로/아웃트로) 10분 정도로 배분 권장.

## 8. 완성 & MIDI 내보내기 (10분)

위자드 **"★ 완성"** 단계로 이동합니다.

1. 상단 재생 순서 타임라인에서 인트로→벌스→프리코러스→코러스→아웃트로 순서를 눈으로 확인 → "▶ 재생"으로
   전체 곡을 처음부터 끝까지 들어본다.
2. 믹서에서 피아노/베이스/드럼/스트링 4개 트랙 볼륨을 조절해보고, 필요하면 M(뮤트)/S(솔로)로 특정 트랙만
   들어본다.
3. **"MIDI 내보내기"** 버튼을 눌러 `.mid` 파일을 다운로드한다. (`.json` 저장은 나중에 이어서 편집하고
   싶을 때 쓰는 것이라고 짧게만 언급)

**강사 체크포인트:** MIDI 다운로드가 안 되면 브라우저의 다운로드 차단 팝업(주소창 근처)을 확인하도록 안내.

## 9. 개러지밴드로 불러와 악기 바꾸기 (15분)

1. 다운로드한 `.mid` 파일을 더블클릭하거나 개러지밴드로 드래그해서 새 프로젝트로 연다.
2. 트랙이 **피아노 / 베이스 / 드럼 / 스트링** 4개로 자동 분리되어 들어오는 것을 확인 (Chord Studio가
   악기별로 트랙을 나눠서 내보내기 때문).
3. 각 트랙을 선택해 악기(예: 피아노 → 일렉트릭 피아노나 신스, 스트링 → 다른 종류의 패드)로 바꿔보고
   재생하며 비교한다.
4. **알려진 특이사항**: 개러지밴드가 베이스 트랙을 가끔 "+12 반음" 악기로 자동 매핑해 원래보다 한 옥타브
   높게 들릴 수 있습니다 — 개러지밴드 쪽 악기 선택 특성이며 파일 자체 문제가 아니니, 베이스가 이상하게
   높게 들리면 트랙 악기를 일반 베이스 계열로 바꾸도록 안내한다.
5. 템포는 Chord Studio에서 설정한 BPM 그대로 들어오므로 별도 조정이 필요 없다.
6. 시간이 남으면 볼륨 자동화나 리버브 등 개러지밴드 자체 이펙트를 살짝 얹어보게 한다(선택 사항).

## 10. 마무리 공유 & Q&A (5분)

- 시간이 되는 학생 1~2명의 곡을 재생해서 함께 듣는다.
- 오늘 배운 흐름을 한 줄로 정리: **"AI에게 질문 → Chord Studio에서 귀로 확인하며 다듬기 → MIDI로
  내보내기 → 개러지밴드에서 악기 입히기."**
- 다음 단계 제안: 오늘 만든 `.json` 파일을 저장해두면 다음에 이어서 편집할 수 있고, 같은 방식으로
