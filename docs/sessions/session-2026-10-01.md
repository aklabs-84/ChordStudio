- `apps/studio/src/App.tsx`: `previewChord = (symbol) => engineRef.current?.previewChord(symbol)` 콜백을 만들어 `<ChordEditor>`(만들기 탭), `<Wizard>`(레슨 탭), `<ChordInputView>`(코드 입력 탭)에 `onPreviewChord`로 전달.
- `apps/studio/src/components/ChordEditor.tsx`: 코드 버튼 `onClick`에서 기존 `setSel(...)` 토글에 더해 `onPreviewChord?.(c.symbol)` 호출 추가 (새 UI 요소 없음, 클릭 시 자동 재생).
- `apps/studio/src/components/Wizard.tsx`: `onPreviewChord` prop을 받아 내부 `<ChordEditor>` 호출에 그대로 전달.
