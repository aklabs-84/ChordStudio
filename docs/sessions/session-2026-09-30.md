1) 샘플 4곡(`docs/samples/*.json`)의 화성을 `generateSong()`이 무작위로 고른 장르별 진행 대신, 모든 코드 섹션(Intro/벌스/프리코러스/코러스/아웃트로)에 `degreesToChords(["I","V","vi","IV"], key)` 기반의 고정 진행으로 다시 생성. 장르별 BPM/스윙/드럼·베이스·피아노 패턴(`getPreset(genre)`)과 기존 확장 구조(벌스·코러스 반복, 손으로 다듬은 임베리시먼트)는 그대로 유지. `docs/samples/README.md`도 새 화성 내용에 맞게 갱신.
2) 반복재생/한 번만 재생 토글 기능 추가 — 계획을 사용자에게 제시해 승인받음: `packages/core/src/engine.ts`에는 이미 `setLoop`/`onEnded`가 구현돼 있으나 UI에서 전혀 쓰이지 않고 있었음. `apps/studio/src/App.tsx`에 `loop` 상태 추가 + `engineRef.current?.setLoop(loop)` 연동 + 헤더에 "반복재생/한 번만" 버튼 추가, `apps/studio/src/components/Wizard.tsx`에도 동일 prop/버튼 추가.
**결과:** 1) 완료 — `docs/samples/*.json` 4곡(팝/로파이/록/재즈) 전부 모든 코드 섹션을 I-V-vi-IV로 재생성, `docs/samples/README.md` 갱신. 공유 링크(#s=...) 경유 브라우저 검증은 자동화 환경이 `window.confirm()`을 강제로 `false` 처리해 앱의 "고친 내용 사라짐" 확인창을 통과하지 못하는 문제가 있어, 대신 `localStorage["chord-studio:autosave:v1"]`에 각 샘플 JSON을 직접 심고(Vite `/@fs/` 경로로 fetch) 새로고침하는 방식으로 우회 검증함. 4곡 모두 제목·화성(팝 Bb-F-Gm-Eb, 로파이 D-A-Bm-G, 록 Db-Ab-Bbm-Gb, 재즈 Bb-F-Gm-Eb)과 8마디 확장 구조·장르별 임베리시먼트가 정상 렌더링됨을 확인.
2) 완료 — `App.tsx`(만들기 탭 헤더)와 `Wizard.tsx`(레슨 탭 재생 버튼 옆)에 "반복재생/한 번만" 토글 버튼을 추가하고, `loop` 상태를 `engineRef.current?.setLoop(loop)`으로 연동함. 검증 도중 `packages/core/src/engine.ts`의 실제 버그를 발견: "한 번만" 모드에서 곡이 끝났을 때 호출되는 `onEnded` 콜백이 `Tone.getDraw()`(requestAnimationFrame 기반)를 거쳐 실행되도록 되어 있어, 브라우저 탭이 비활성/백그라운드거나 rAF가 스로틀되면 `onEnded`가 지연되거나 아예 실행되지 않는 문제가 있었음(반면 `transport.stop()`/`playing=false`는 오디오 클록으로 정확히 실행되어, 소리는 멈췄는데 재생 버튼은 "■ 정지" 상태로 안 바뀌는 상황이 생길 수 있었음). `Tone.getDraw()` 경유를 없애고 `onEnded`를 스케줄 콜백에서 직접 호출하도록 수정. 수정 후 앱 모듈 그래프 안에서 임시 테스트 모듈로 직접 검증: 1) 한 번만 모드 — 3.2초짜리 축소 테스트곡 재생 후 3.3초 만에 `onEnded` 정상 호출 및 `isPlaying()`이 `false`로 전환됨을 확인, 2) 반복재생 모드 — 6초 대기 동안(곡 1바퀴 이상 재생) `onEnded`가 호출되지 않고 `isPlaying()`이 계속 `true`로 유지되며 재생 위치가 정상적으로 순환됨을 확인. `npx tsc --build` 통과. 브라우저 "만들기" 탭에서 토글 버튼 UI(선택 상태 하이라이트)도 스크린샷으로 확인(`docs/sessions/screenshots/20260930-122359-after-loop-toggle-ui.png`) — "레슨" 탭은 이 자동화 브라우저 환경의 `window.confirm()` 강제 `false` 처리 때문에 탭 전환 확인창을 통과하지 못해 화면 캡처는 생략했으나, `Wizard.tsx`는 `App.tsx`와 동일한 prop 구조로 연결되어 있고 `tsc` 통과·엔진 레벨 동작 검증이 완료되어 있어 기능상 문제 없음.
